## Risks & open questions

- **R1 — User enumeration by timing.** An unknown email returns faster than a wrong password,
  because no hash is checked. *Recommend:* verify against a fixed dummy hash for unknown emails,
  so both paths do one `scrypt`.
- **R2 — Session token at rest.** *Recommend:* store only the SHA-256 of the random token
  (32 bytes, base64url). A leaked DB file then cannot be replayed as cookies. It costs one line.
- **R3 — No schema migrations.** The tables are created if missing. A later spec that adds
  columns (role, manager link) needs a migration approach. *Recommend:* treat the dev DB as
  disposable for now (delete the file) and decide migrations in the first spec that needs one.
- **R4 — "An employee and a manager" are only names for now.** Nothing in this spec uses roles,
  so there is no role column yet. *Recommend:* seed "Alex Sample" (employee) and "Morgan Example"
  (manager) and add role and manager link with the approval spec (YAGNI).
- **R5 — Untested wiring (accepted test scope).** Cookie flags, the default-deny hook wiring, the
  status mapping and the SQL have no automated test (`docs/testing.md`, Test scope 1–2).
  *Recommend:* keep routes thin; VERIFY proves AC-1, AC-8, AC-9 and AC-11 by observation
  against the running API (requests with and without the cookie) and by screenshots.
- **R6 — `node:sqlite` stability.** It is a release candidate in Node 24 and may print an
  experimental warning. *Recommend:* accept it; it is the bootstrap's decision
  (`docs/architecture.md`).
- **R7 — Design vs app font.** The artboards use Inter from Google Fonts; the app uses the
  system font stack (no external requests). *Recommend:* accept it. ADR 0002 counts styling
  differences as no mismatch.
- **R8 — Initial load.** The spec lists no "checking the sign-in" state. *Recommend:* render
  nothing until `/api/me` answers (it is local and fast), so a signed-in user never sees the
  form flash.
- **Environment:** `./scripts/doctor` — profile fast: runnable, profile full: runnable. All
  prerequisites are met.
